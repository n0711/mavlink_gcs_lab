# Roadmap

## V1 Portfolio Scope

- Flutter Linux desktop dashboard
- Rust receive-only telemetry boundary
- UDP JSON telemetry adapter on `127.0.0.1:16000`
- sample telemetry sender
- optional receive-only MAVLink-to-JSON helper
- offline/read-only parameter parser and diff
- local JSONL diagnostics
- safety lockouts

## V2 Ideas

- Rust-native receive-only MAVLink parser
- richer replay workflow
- public/offline map view
- public parameter metadata integration
- packaging and screenshots for portfolio presentation

## Explicitly Deferred

- command authority
- mission upload
- parameter writes
- MAVSDK server integration
- gRPC/protobuf command services
- certified or production claims
